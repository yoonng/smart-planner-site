빌드 기록

Smart Planner의 출시 준비 상태와 공개 가능한 변경 내용을 정리합니다.

Smart Planner는 현재 Android 출시를 준비하고 있습니다. 실제 배포 빌드가 제공되면 공개 릴리즈 노트를 계속 업데이트합니다.

현재 상태

Android v1 준비

상태: 내부 테스트 및 Google Play 출시 준비.

  • 로컬 우선 Loop Planner 기반
  • 현재 단계를 완료한 뒤 다음 알림을 생성하는 단계 기반 Spaced Loop
  • 홈 화면의 NOW, TODAY, LATER, WAITING 그룹
  • 생성된 reminder occurrence 기준의 홈 통계와 Insights
  • Routine Loop 및 Review 흐름
  • 기본 PRO 기능과 Google Play 구매 연동 준비
  • 데이터 안전, 지원, 개인정보 처리방침과 이용약관 페이지 준비

최근 내부 업데이트

Occurrence 기반 홈과 Insights 모델

홈의 개수와 Insights 통계는 실제로 생성된 알림 행을 기준으로 계산합니다. 아직 생성되지 않은 패턴의 미래 단계는 미리 포함하지 않습니다.

  • 완료: 오늘의 운영일 안에서 완료된 실제 알림
  • NOW: 현재 시간이 되었거나 지난 알림
  • TODAY: 오늘의 운영일 안에서 나중에 예정된 알림
  • LATER: 오늘 이후에 예정된 알림
  • WAITING: 완료되지 않은 실제 알림이 없는 활성 Loop

플랫폼 계획

  • Android: 첫 출시 대상
  • iOS: Android 안정화 후 진행 예정
  • 태블릿, PC, Mac: 순차 출시 검토

안내

테스트 중에는 빌드 내용이 변경될 수 있습니다. 공개되는 정보는 사용자가 이해하기 쉽도록 간단하고 명확하게 유지합니다.
