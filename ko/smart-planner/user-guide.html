초보자 01

Smart Planner가 하는 일

기억하고 싶은 내용과 반복하고 싶은 행동을 필요한 시점에 다시 보여줍니다.

기억과 학습

Spaced Loop

단어, 사실, 발표 내용, 업무 절차처럼 나중에 다시 떠올리고 싶은 내용을 등록합니다.

반복 행동

Routine Loop

약 복용, 운동, 청소, 점검처럼 정해진 일정에 따라 반복하는 행동을 등록합니다.

Smart Planner는 복습 시점을 관리합니다

메모를 보기 전에 먼저 기억을 떠올린 다음 내용을 확인하고, 자신의 결과에 맞는 버튼을 선택하세요.

초보자 02

어떤 Loop를 선택해야 하나요?

항목의 이름보다 사용 목적을 기준으로 선택하세요.

Spaced Loop를 선택하세요

  • 내용을 기억하고 싶을 때
  • 현재 복습을 끝낸 뒤 다음 복습을 예약할 때
  • 단계마다 복습 간격이 달라질 수 있을 때

Routine Loop를 선택하세요

  • 행동을 반복하고 싶을 때
  • 매일, 특정 요일 또는 정기 시간에 실행할 때
  • 완료한 뒤 다음 Routine을 예약할 때

한 가지 목표에 두 Loop를 함께 사용할 수 있습니다

‘매일 저녁 영어 공부하기’는 Routine Loop로 만들고, 새로 배운 단어는 각각 Spaced Loop로 만들 수 있습니다.

초보자 03

홈 화면 이해하기

홈은 알림을 처리해야 하는 시점에 따라 나누어 보여줍니다.

NOW지금 복습하거나 완료할 수 있는 항목입니다.
TODAY오늘 나중에 예정된 항목입니다.
LATER오늘 이후에 예정된 항목입니다.
초보자 04

첫 Spaced Loop 만들기

기억하고 싶은 단어, 사실, 아이디어 또는 메모를 등록해 보세요.

1 시작2 내용 입력3 패턴 확인4 저장
1

+ Spaced Loop 누르기

홈에서 파란색 + Spaced Loop 버튼을 누릅니다.

2

제목과 메모 입력하기

제목은 짧게 쓰고, 정답이나 설명은 메모에 입력합니다.

3

추천 패턴 그대로 사용하기

첫 Loop에서는 기본 복습 패턴을 변경하지 않아도 됩니다.

4

첫 알림 확인 후 저장하기

첫 알림 시간을 확인하고 Save를 누릅니다.

완료했습니다

Loop가 홈에 나타납니다. 복습 시간이 되면 메모를 열기 전에 먼저 답을 떠올려 보세요.

초보자 05

Recall 결과와 다음 복습

Spaced Loop를 열고 자신이 얼마나 잘 기억했는지에 맞는 결과를 선택하세요.

Again아직 잘 기억하지 못했습니다.
Hard어렵게 기억해 냈습니다.
Got it만족스럽게 기억했습니다.
Easy매우 쉽게 기억했습니다.
In 5 minutes지금 처리하기 어려울 때 잠시 미룹니다.
초보자 06

첫 Routine Loop 만들기

정기적으로 반복하는 행동을 등록합니다. 파란색 영역을 따라 각 설정을 찾으세요.

1

제목과 메모 입력하기

행동의 이름은 짧게 씁니다. 체크리스트나 추가 설명이 필요할 때만 메모를 입력하세요.

2

반복 규칙 선택하기

매일, 평일, 주말 또는 원하는 요일처럼 행동을 반복할 시점을 선택합니다.

3

일정 설정 후 저장하기

요일과 시간을 선택하고 알림 설정을 확인한 다음 Save를 누릅니다.

4

저장된 Routine 확인하기

저장 후 Routine을 열어 메모, 카테고리, 반복 설정을 확인합니다.

Routine을 완료하는 방법

Routine이 NOW 또는 TODAY에 나타나면 카드를 열고 행동을 마친 뒤 Complete를 누르세요. 그러면 다음 Routine이 자동으로 예약됩니다.

기능 01

Focus Timer

Focus Timer는 선택한 반복 횟수만큼 집중 학습 시간과 짧은 휴식을 번갈아 진행합니다. 이 리듬은 꾸준히 집중하고 학습 내용을 기억하는 데 도움이 됩니다.
다음 네 단계로 시작하세요.

1

Focus Timer 열기

홈에서 메인 메뉴를 열고 Focus Timer를 누릅니다.

2

템플릿 선택하기

원하는 타이머 템플릿의 파란색 재생 버튼을 누릅니다.

3

타이머 시작하기

반복 횟수와 연결할 Loop를 확인하고 Start Focus Timer를 누릅니다.

4

집중 세션 진행하기

시간이 끝날 때까지 집중하세요. 언제든 일시정지하거나 세션을 끝낼 수 있습니다.

기능 02

백업과 복원

Sync / Backup 화면을 열고 안내를 읽은 뒤 백업 파일을 만들거나 복원하세요.

1

Sync / Backup 열기
메인 메뉴에서 선택합니다.

2

백업 만들기
백업 작업을 선택하고 파일을 안전하게 저장합니다.

3

파일 보호하기
비밀번호를 추가했다면 잃어버리지 않도록 보관합니다.

4

신중하게 복원하기
복원 전에 파일과 비밀번호를 확인합니다.

백업하기 전에

백업에 포함되는 내용을 확인하고 비밀번호를 안전한 곳에 보관하세요.

복원하기 전에

선택한 파일이 맞는지, 현재 데이터가 바뀌는지 먼저 확인하세요.

기능 03

Insights

Insights는 PRO에서만 사용할 수 있습니다. PRO를 활성화한 뒤 메인 메뉴에서 Insights를 열면 주간 학습과 활동 요약을 확인할 수 있습니다.

PRO 기능

Weekly Insights는 PRO가 활성화된 뒤 사용할 수 있습니다. 숫자를 더 많은 일을 해야 한다는 압박이 아니라 학습 상태를 확인하는 참고 자료로 사용하세요.

기능 04

설정

왼쪽 위 메인 메뉴를 열고 Settings를 선택합니다.

기능 05

PRO

PRO 안내 화면에서 제공 기능과 구매·복원 정보를 확인할 수 있습니다.
