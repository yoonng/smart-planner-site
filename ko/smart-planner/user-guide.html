초보자 01

Smart Planner가 하는 일

기억하고 싶은 정보와 반복해야 하는 행동을 필요한 시점에 다시 보여줍니다.

기억과 학습

Spaced Loop

시간 간격을 두고 정보를 다시 확인할 때 사용합니다. 단어, 시험 내용, 업무 절차, 사람 이름처럼 잊고 싶지 않은 지식에 적합합니다.

반복 행동

Routine Loop

정해진 주기에 따라 행동을 반복할 때 사용합니다. 약 복용, 운동, 재고 점검, 청소, 주간 보고 등에 적합합니다.

간격을 둔 복습은 기억에 어떻게 도움이 되나요?

처음 학습한 뒤 비교적 짧은 시간 안에 다시 확인하면 내용이 빠르게 사라지는 것을 줄이는 데 도움이 될 수 있습니다. 이후 복습 간격을 늘리면 며칠, 몇 주, 몇 달 뒤에도 다시 떠올릴 기회를 만들 수 있습니다.

Smart Planner가 기억을 자동으로 만들어 주거나 결과를 보장하는 것은 아닙니다. 먼저 스스로 떠올리고, 확인하고, 틀린 부분을 수정할 수 있도록 복습 시점을 관리합니다.

초보자 02

어떤 Loop를 선택해야 하나요?

제목보다 그 항목의 목적을 기준으로 선택하세요.

Spaced Loop를 선택하세요

  • 내용을 기억하고 싶을 때
  • 현재 복습을 끝낸 뒤 다음 복습이 생성되어야 할 때
  • 단계마다 복습 간격이 달라질 수 있을 때

Routine Loop를 선택하세요

  • 행동을 반복하고 싶을 때
  • 매일, 요일, 정기 시간에 실행할 때
  • 완료 후 다음 정기 일정이 준비되어야 할 때

하나의 목표에 두 종류를 함께 사용할 수 있습니다

“매일 저녁 영어 공부하기”는 Routine Loop로 만들고, 그 시간에 배운 개별 단어나 표현은 Spaced Loop로 만들 수 있습니다.

초보자 04

첫 Spaced Loop 만들기

처음에는 한 가지 작은 정보로 시작하세요.

Create에서 Spaced Loop 선택

홈에서 Create를 열고 기억 또는 학습 목적의 Loop를 선택합니다.

짧은 제목 입력

예: 회복력. 짧은 제목은 홈과 알림에서 알아보기 쉽습니다.

설명 또는 정답 입력

예: 어려움을 이겨내고 다시 일어서는 힘. 메모를 보기 전에 먼저 뜻을 떠올려 보세요.

초보자용 패턴 선택

현재 앱에 표시된 기본 학습 패턴 또는 오늘 중심 패턴을 선택합니다.

화면 아래까지 확인 후 저장

폼의 하단으로 스크롤해 첫 알림 시간과 알림 설정을 확인한 뒤 저장합니다.

복습 효과를 높이는 습관

알림이 나타나면 바로 메모를 읽지 말고 먼저 기억을 떠올리세요. 그다음 메모를 열어 빠진 부분을 확인하고 현재 단계를 완료합니다.

초보자 05

첫 Routine Loop 만들기

명확한 반복 시간이 있는 실제 행동으로 시작하세요.

Create에서 Routine Loop 선택

지식을 복습하는 것이 아니라 행동을 반복하는 것이 목적일 때 선택합니다.

행동 입력

예: 주간 냉장고 점검. 메모에는 온도, 유통기한, 청소 상태 확인을 적을 수 있습니다.

반복 규칙 선택

예: 매주 금요일 오후 5시. 화면에 표시된 요일과 시간 설정을 사용합니다.

화면 하단 확인 후 저장

반복 규칙과 알림 설정을 마지막까지 확인한 뒤 저장합니다.

현재 항목 완료

행동을 마친 뒤 Complete를 선택하면 Routine 규칙에 따라 다음 일정이 준비됩니다.

초보자 06

Complete, Snooze, Recall

화면에 따라 완료 버튼의 정확한 이름은 달라질 수 있지만 각 동작의 목적은 같습니다.

Complete / Got it현재 알림을 처리한 뒤 사용합니다. 결과가 기록되고 다음 단계 또는 다음 반복 일정이 준비될 수 있습니다.
Snooze항목은 유효하지만 잠시 미루고 싶을 때 사용합니다. 선택한 시간만큼 현재 알림이 뒤로 이동합니다.
Recall now예정 시간 전이라도 지금 바로 해당 Loop를 Recall 가능한 상태로 가져오고 싶을 때 사용합니다.
초보자 07

Focus Timer 사용하기

공부나 작업을 시작하기 어렵다면 짧은 집중 시간부터 시작하세요.

Focus Timer 열기

홈 또는 메뉴에서 Focus Timer로 이동합니다.

짧은 시간 선택

처음에는 10~15분처럼 부담이 적은 시간을 사용해도 됩니다. 테스트 캡처에서는 2분 Focus와 1분 Break를 사용합니다.

시작·일시정지·재개

진행 중에는 남은 시간과 ongoing notification을 확인할 수 있습니다.

중급

다음에 알아볼 기능

패턴과 일정 변경

Spaced 패턴이나 Routine 규칙을 바꿀 때 앞으로 생성될 알림이 어떻게 달라지는지 확인합니다.

설정과 시간

기상 시간, 취침 시간, Day boundary, 시간대, 알림과 배터리 제한을 확인합니다.

백업과 복원

암호로 보호된 백업을 만들고, 비밀번호를 안전하게 보관하고, 복원 후 결과를 확인합니다.

Insights

완료 기록과 생성된 occurrence를 기준으로 통계를 해석합니다.

페이지 관리 원칙

탐색, 로딩, 가독성이 편안한 동안에는 이 설명서를 한 페이지로 유지합니다. 특정 섹션이 지나치게 커지거나 모바일 사용성이 명확히 나빠질 때만 별도 페이지로 분리합니다.
