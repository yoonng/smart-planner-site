# Feathly website repository SSOT

This repository is the source of truth for the public Feathly website.

## Canonical repository

- Public domain: `https://feathly.com`
- Website repository: `yoonng/smart-planner-site`
- Default branch: `main`
- Deployment source: GitHub Pages from repository root `/`

## Important boundary

Do **not** use `yoonng/feathly-docs` for the public `feathly.com` website, Smart Planner Privacy Policy, Terms, FAQ, Support pages, Closed Test pages, user guide, or other live website copy.

`yoonng/feathly-docs` is not the active public website source for `feathly.com`.

## Public policy paths

- English Privacy Policy: `smart-planner/privacy.html`
- Korean Privacy Policy: `ko/smart-planner/privacy.html`
- English Terms: `smart-planner/terms.html`
- Korean Terms: `ko/smart-planner/terms.html`
- English FAQ: `smart-planner/faq.html`
- Korean FAQ: `ko/smart-planner/faq.html`

## Agent instruction

Before editing any public Feathly website or policy copy, confirm the repo is `yoonng/smart-planner-site`. If another repo is selected, stop and correct the repository target before making changes.
