Beginner 01

What Smart Planner does

Feathly helps you bring back information you want to remember and actions you want to repeat.

For memory and learning

Spaced Loop

Use a Spaced Loop for vocabulary, facts, presentation notes, work procedures, or anything you want to recall again later.

For repeating actions

Routine Loop

Use a Routine Loop for scheduled actions such as medication, exercise, cleaning, inspections, or weekly checks.

Feathly manages timing, not memory itself

Try to recall first, then check the note and choose the result that matches your attempt.

Read the learning science overview

Beginner 02

Which Loop should you choose?

Choose by the purpose of the item, not only by its title.

Choose Spaced Loop when...

  • You want to remember content.
  • The next review follows completion of the current review.
  • The gap between reviews can change across steps.

Choose Routine Loop when...

  • You want to repeat an action.
  • The action follows a day, weekday, or regular time.
  • Completing it should prepare the next occurrence.

One goal can use both types

“Study English every evening” can be a Routine Loop. Each new word can be a separate Spaced Loop.

Beginner 04

Create your first Spaced Loop

Use a Spaced Loop for a word, fact, idea, or note you want to remember.

1 Start 2 Add content 3 Keep the pattern 4 Save
1

Tap + Spaced Loop

From Home, tap the blue + Spaced Loop button.

2

Enter a title and note

Keep the title short. Put the answer or explanation in the note.

3

Keep the suggested pattern

For your first Loop, leave the default review pattern unchanged.

4

Check the first reminder and save

Confirm the first reminder time, then tap Save.

Done

The Loop will appear on Home. When it is ready, try to remember the answer before opening the note.

Beginner 06

Create your first Routine Loop

Use a Routine Loop for an action that repeats on a regular schedule. Follow these four steps and use the blue box on each image to find the setting.

1

Enter a title and note

Give the action a short name. Add a note only when you need a checklist or extra instructions.

2

Choose the repeat rule

Select how often the action repeats, such as daily, weekly, or monthly.

3

Set the schedule and save

Choose the day and time, check notification options, and then tap Save.

4

Review the saved Routine

After saving, open the Routine and confirm its note, category, and repeat settings. Complete an occurrence later from the due item on Home.

Feature 01

Focus Timer

Open Focus Timer, choose the session settings, and then run the focus session.

1

Open Focus Timer

From Home, open the main menu and tap Focus Timer.

2

Choose the session settings

Select a template, set the repeat count, optionally link a Loop, and tap Start Focus Timer.

3

Run the focus session

The timer shows the current focus block. Use the controls to pause or end the session.

Focus Timer flow

Menu → Session settings → Start Focus Timer → Running session.
