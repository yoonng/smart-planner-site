Beginner 01

What Smart Planner does

Smart Planner helps you bring back information you want to remember and actions you want to repeat.

For memory and learning

Spaced Loop

Use a Spaced Loop when you want to review information again after a gap. It is suitable for vocabulary, exam topics, work procedures, names, and other knowledge you do not want to forget.

For repeating actions

Routine Loop

Use a Routine Loop when an action should happen on a regular schedule, such as taking medicine, exercising, checking stock, cleaning, or submitting a weekly report.

How can spaced review help memory?

Reviewing shortly after learning can help you return to information before it fades. Increasing the time between later reviews gives you repeated opportunities to retrieve it over days, weeks, or months.

Smart Planner does not create memory automatically or guarantee an outcome. It manages the timing so you can try to recall first, then check and correct.

Beginner 02

Which loop should you choose?

Use the purpose of the item, not only its title, to choose the loop type.

Choose Spaced Loop when...

  • You want to remember content.
  • The next review should happen after the current review is completed.
  • The gap between reviews may change across steps.

Choose Routine Loop when...

  • You want to repeat an action.
  • The action follows a day, weekday, or regular time.
  • Completing it should prepare the next regular occurrence.

One goal can use both types

“Study English every evening” can be a Routine Loop. The individual words or expressions learned during that session can each use a Spaced Loop.

Beginner 04

Create your first Spaced Loop

Use one small piece of information for your first example.

Open Create and choose Spaced Loop

Start from Home and select the option for a learning or memory-based loop.

Enter a short title

Example: resilience. A short title is easier to recognise in Home and in a notification.

Add the answer or explanation

Example note: the ability to recover from difficulty. Try to recall it before opening or reading the note.

Choose a beginner pattern

Select the default or today-focused study pattern shown in your build. The pattern determines how the next review step is scheduled.

Check the first reminder and save

Scroll to the bottom of the form, confirm the first time and notification settings, then save the loop.

Better review habit

When the reminder appears, pause and try to remember the answer first. Then open the note, check what was missing, and complete the step.

Beginner 05

Create your first Routine Loop

Use a real action with a clear repeating time.

Open Create and choose Routine Loop

Choose Routine when the purpose is to repeat an action rather than review knowledge.

Enter the action

Example title: Weekly fridge check. Optional note: temperature, expiry dates, and cleaning condition.

Select the repeat rule

Example: every Friday at 5:00 PM. Use the weekday and time controls shown in the form.

Scroll to the final action and save

Confirm the repeat rule and notification settings at the bottom before saving.

Complete the occurrence

When the action is done, choose the completion action. Smart Planner prepares the next scheduled occurrence according to the routine.

Beginner 06

Complete, Snooze, and Recall

The exact completion label may differ by screen, but the purpose of each action is consistent.

Complete / Got it Use after you have handled the current reminder. The result is recorded and the next step or occurrence can be prepared.
Snooze Use when the item is valid but you need a short delay. The current reminder moves to the selected later time.
Recall now Use when you want to bring a loop into a recall-ready state before its planned reminder time.
